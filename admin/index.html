Entegrasyon Kılavuzu

iyzico API'yi sitenize bağlamak için adımlar

1
iyzico Merchant hesabı açın

merchant.iyzipay.com/register adresinden ücretsiz hesap oluşturun.

2
API anahtarlarınızı alın

Merchant Panel → Ayarlar → API Bilgileri bölümünden API Key ve Secret Key'i kopyalayın.

3
Yukarıdaki formu doldurun

Önce Sandbox ortamında test edin, her şey çalışınca Production'a geçin.

4
Backend entegrasyonu

Ödeme işlemleri için bir backend (Node.js, PHP vb.) gereklidir. API anahtarları burada saklanır ve hazır olduğunda backend koduna aktarılır.
